Apex Exchange — Simulated Digital Asset Exchange

A simulation-only exchange-engineering project with a Decimal-based deterministic matching engine. It applies price-time priority, executes at the resting maker price, supports partial fills and cancellation, and exposes the book and trades through a FastAPI API.

  • Pure Python matching engine with bid/ask price levels, FIFO queues, order state transitions and deterministic trade identifiers
  • REST endpoints for order submission, order lookup, cancellation, order-book snapshots and recent trades; Next.js dashboard supports test-order entry
  • 23 backend tests pass, including property-based order-stream conservation and book invariants; next: simulated balances, ledger, persistence and replay

Agentic RAG Document Q&A

A local-first document question-answering engine for PDF, DOCX, Markdown and text files. It combines MiniLM embeddings with lexical retrieval, then selects evidence from relevant passages and cites the source file and page — without calling a hosted answer-generation API.

  • LangGraph workflow retrieves and grades chunks, rewrites weak queries, validates citation indices and abstains when evidence is insufficient
  • Hybrid vector and BM25-style lexical ranking improves technical-term, acronym and exact-name retrieval across FAISS or ChromaDB
  • Deterministic local extractive answers, page-level citations, persistent source uploads, diagnostic retrieval endpoint and a labeled quality-evaluation harness
  • Python
  • LangGraph
  • MiniLM
  • FAISS
  • ChromaDB
  • Hybrid retrieval
